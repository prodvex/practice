# GamingClub.Android

Планируемый Android-клиент на Kotlin (Android Studio).

Экраны: вход, регистрация, схема зала, выбор времени/тарифа,
мои бронирования, текущая сессия с таймером и продлением.

**Статус:** проект Android Studio ещё не создан. Финальная версия будет работать с GamingClub.API, не с локальной заглушкой.
