# План тестирования

Не менее 15 unit-тестов, из них 8 на алгоритм тарификации и граничные случаи:
нулевая и отрицательная длительность, обычные часы, Happy Hours, ночь через полночь,
границы льготных окон, пакет часов, продление.

Не менее 5 интеграционных тестов API: создание/отмена брони, конфликт интервалов,
смежные интервалы, гонка двух клиентов, доступ к защищённым операциям.

Цель покрытия алгоритмического модуля: ≥70%. Сейчас тесты не созданы.
