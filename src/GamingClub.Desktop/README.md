# GamingClub.Desktop

Windows-клиент администратора на C#, WPF и .NET 8. Данные загружаются через GamingClub.API.

Реализованы вход ADMIN, загрузка мест, список бронирований, отмена будущих броней, управление тарифами, расчёт загрузки, CSV-экспорт и продление активной сессии.

Ограничения текущей версии — нет рабочей release-конфигурации с production HTTPS, нет автоматического завершения сессии по истечении времени и UI-приёмка на физическом Windows-компьютере не подтверждена.

Для запуска задайте `GAMINGCLUB_API_URL`, настройте API и SQL Server, затем соберите `GamingClub.Desktop.csproj` в Visual Studio или GitHub Actions.
