# Статическая ревизия GamingClub (без сборки)

**Дата подготовки заметок:** 18.11.2026.  
**Статус:** проверены некоторые исходники и логика по тексту, но **.NET, SQL, Android и браузерный прототип не запускались**. Полноценный синтаксический анализ делает компилятор при будущей сборке.

## Что проверено без сборки

- Файлы шести SVG-экранов и WPF XAML доступны в GitHub.
- Текстовая проверка вложенности тегов XML не выявила незакрытых элементов в шести SVG и основном WPF XAML. **Это не полная XAML/XML-валидация.**
- HTML-прототип ссылается на шесть SVG и содержит переходы между разделами.
- В исходниках есть проверки точности UTC времени до минуты.
- В API присутствует политика ограничения запросов входа/регистрации.

## Как запустить проверки позже

### 1. Лёгкая статическая проверка без компиляции

После клонирования GitHub-репозитория:

```powershell
python scripts/static_audit.py
```

Она проверяет наличие ключевых файлов, шести SVG, формальную корректность XML и набор ожидаемых таблиц/маршрутов. Это **не тест бизнес-логики** и не замена `dotnet build`.

### 2. Проверка из GitHub Actions

Добавлен ручной workflow `.github/workflows/manual-build.yml`. Он запускается только по **Actions → GamingClub — manual build and checks → Run workflow**, вручную, и не запускается при каждом новом коммите. До явного запуска workflow ни одна проверка CI не считается выполненной.

Workflow проверяет API/WPF и запускает xUnit на Windows. SQL-тесты без отдельного SQL Server пропускаются с пометкой Skipped. Android APK он не собирает.

### 3. Полная проверка перед защитой

1. Сборка ASP.NET Core API и WPF на Windows.
2. SQL Server `GamingClubTest_18`: интеграционные тесты, миграции, одновременные запросы.
3. Android Studio: собрать debug APK и проверить регистрацию, бронирование, таймер и отмену.
4. Сохранить фактические отчёты xUnit/coverage и скриншоты.
5. Повторно проверить матрицу прав, что `/api/dev/*` недоступны в Production.

## Открытые вопросы

- Нет проверенной сборки/работающего APK и покрытие 70% не подтверждено.
- Android-код остаётся в `feature/android-client` — открытый PR нельзя считать объединённым.
- Ограничение скорости запросов сейчас внутрипроцессное, по IP. Для реального хостинга понадобятся учёт прокси/распределённых серверов, HTTPS и защита от перебора.
- SVG-макеты и HTML-прототип **не заменяют настоящий Figma-проект**.
- Не заявлять об успешных тестах и завершённой практике до реального запуска.
