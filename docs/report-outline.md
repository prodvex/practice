## Предлагаемое содержание

1. **Введение**: цель, предметная область, задачи, актуальность и ограничения.
2. **Анализ предметной области**: роли посетителя/администратора, сравнение не менее трёх реальных аналогов с проверенными источниками, функциональные требования.
3. **Проектирование**: ER-модель 8 таблиц (`docs/er-diagram.md`), связи, 3NF, архитектура, REST API и права доступа (`docs/architecture.md`).
4. **Дизайн интерфейса**: шесть макетов SVG из `docs/design/`, фреймы Figma (созданы) и ещё не настроенные связи прототипа навигации; ссылка: https://www.figma.com/design/Gh6UqShvMOH9IWPghqE95P.
5. **Реализация**: SQL Server, ASP.NET Core API, алгоритм тарификации и загрузки, Android/Kotlin, Windows/WPF, JWT.
6. **Проверка и тестирование**: таблица тест-кейсов, реальные результаты unit/integration, покрытие ≥70% с приложенным отчётом инструмента; при необходимости обнаруженный дефект и отдельный fix-коммит с регрессионным тестом.
7. **Результат**: скриншоты фактически работающих Android, ПК, Swagger, SQL Server; инструкция сборки, APK, ограниченные возможности и развитие.
8. **Заключение**: что реально сделано и чему научился.
9. **Список литературы**: не менее 15 проверенных источников, если это требуется по выданным методическим материалам; нельзя выдумывать библиографию.
10. **Приложения**: ТЗ, ER, API, тест-кейсы, результаты сборки, скриншоты, история Git/PR, ссылка на репозиторий.
