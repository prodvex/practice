## Ответы на типовые вопросы

**Почему API, а не прямое подключение Android к SQL?**  
> API является единой точкой бизнес-правил, авторизации и записи в базу. Android не получает доступ к SQL Server.

**Как защищаетесь от двойной брони?**  
> API использует транзакцию SERIALIZABLE и блокировки места. Второй пересекающийся запрос получает конфликт.

**Почему цена считается на сервере?**  
> Клиентские вычисления можно изменить. Сервер повторно проверяет тариф и рассчитывает итоговую сумму.

**Что означает VOID?**  
> Это аннулирование неоплаченного учебного начисления. Возврат реальных денег не выполняется.

**Почему в Release нет рабочего адреса?**  
> Production HTTPS endpoint ещё не предоставлен. Поэтому Debug-сценарий использует локальный адрес эмулятора, а фиктивный Release URL нельзя выдавать за готовый production.

**Что ещё осталось?**  
> Production HTTPS, физическое устройство, автоматическое завершение сессии, итоговый отчёт с реквизитами, подписи, дневник и презентация.
