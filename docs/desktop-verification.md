# Проверка ПК-приложения GamingClub (Visual Studio)

**Статус:** исходный код загружен, сборка и запуск не проводились.

## Подготовка
1. Установить Visual Studio 2022 с поддержкой .NET desktop/WPF, ASP.NET Core и .NET 8 SDK.
2. Выполнить `database/schema.sql` и `database/seed.sql` на локальном SQL Server.
3. Настроить `ConnectionStrings__GamingClub` и `GAMINGCLUB_JWT_SECRET` по `docs/local-setup.md` и `docs/auth-verification.md`.
4. Зарегистрировать пользователя через `POST /api/auth/register`. По умолчанию его роль `VISITOR`.
5. **Только на локальном тестовом сервере** назначить нужному пользователю роль ADMIN через SSMS под ответственностью преподавателя/разработчика:
   ```sql
   USE GamingClub;
   UPDATE dbo.Users SET RoleId=(SELECT RoleId FROM dbo.Roles WHERE Code='ADMIN')
   WHERE Login=N'admin_for_local_testing';
   ```
   Администратор не создаётся саморегистрацией; эту команду нельзя включать в публичный API.
6. Запустить API: `dotnet run --project src/GamingClub.API --urls http://localhost:5080`. Используйте только локальный Development API; для реальной эксплуатации требуется HTTPS.
7. В Visual Studio открыть `src/GamingClub.Desktop/GamingClub.Desktop.csproj` и запустить проект на Windows. При необходимости настроить переменную `GAMINGCLUB_API_URL`.

## Сценарии
- При запуске список мест подгружается через GET /api/seats.
- Вход с неправильным паролем отображает ошибку.
- Вход под VISITOR **не даёт** перейти к административному отчёту.
- Вход под ADMIN сохраняет JWT только в памяти приложения, позволяет запросить загрузку зала.
- Установить UTC-время начала/конца отчёта, нажать «Рассчитать»; ожидать seatCount, occupied minutes и occupancyPercent.
- Для реального действующего бронирования указать ID и более позднее время UTC; продление вызывает защищённый `/api/sessions/{id}/extend`.
- Если место занято или время неверное, сервер должен отклонить продление; клиент показывает HTTP-код.
- После «Выйти» административные операции должны быть недоступны.

## Ограничения
- WPF-интерфейс ещё не включает полноценное управление всеми тарифами, просмотр всех бронирований и экспорт файла CSV.
- Вход в текущей версии работает по HTTP только для локального прототипа; не использовать для реальных паролей/публичной сети без HTTPS.
- Нет UI-тестов, сборки, скриншотов и фактических результатов.
- Повторная проверка при просроченном JWT ещё необходима.
