# Проверка локальной поставки GamingClub

**26.11.2026.** Windows x64, SQL Server 2025 Express LocalDB, Android 15 x86_64 с WHPX. Автономные сборки API и WPF используют .NET 8. Отладочный APK собран и проверен на эмуляторе.

| Проверка | Результат |
|---|---|
| Комплектный лаунчер | Запускается отдельный экземпляр LocalDB. Готовность API подтверждается по /health. Порт передаётся клиентам. |
| Модульные и интеграционные тесты .NET | 86 из 86, включая SQL Server, HTTP и раздельный учёт PAID/PENDING. |
| JVM-тесты Android | 32 из 32. |
| Android | Вход VISITOR, 12 мест и четыре тарифа из API. Выбор места, бронь, запуск, продление и завершение выполнены в Android UI. |
| Windows | Вход ADMIN, места из API, расчёт выручки в WPF. В контрольном прогоне 0 руб. оплаты и 150 руб. начислений. |
| HTTP/SQL | Часовая бронь 120 руб., повторный пересекающийся запрос 409, уменьшающийся таймер, продление на 15 минут за 30 руб., статус COMPLETED. |
| Защищённые отчёты | Проверены оба CSV, seed 241810 и отказ HTTP 403 для VISITOR. |
| Повторный запуск | STOP завершил стенд. После повторного запуска бронь осталась в базе, пароль VISITOR изменился. |

В отчёте по производственной практике приведены скриншоты WPF и Android. Установка LocalDB и включение компонента WHPX на отдельном ПК с чистой Windows остаются для внешней проверки. Стенд использует синтетические данные.
