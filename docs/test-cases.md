## Дополнительные проверки

- Одновременная попытка бронирования одного места двумя клиентами.
- Неверный ID пользователя, места или тарифа.
- Действие через Production API: маршруты `/api/dev/` должны отсутствовать.
- Проверка SQL на отсутствующие/повторяющиеся записи после отклонённого продления.
- Сборка Android APK и запуск на эмуляторе и физическом устройстве.
- Проверка доступа к данным после реализации авторизации и ролей.

**Примечание:** тесты тарифа привязаны к текущей учебной политике расчёта по UTC и к ценам из `database/seed.sql`. До практического применения нужна политика часового пояса клуба.
