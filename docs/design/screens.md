# Макеты шести экранов Android (вариант 18)

В `docs/design/` подготовлены **шесть отдельных SVG**, по одному макету на экран. SVG можно импортировать в Figma через File → Place image (или drag-and-drop); элементы останутся в векторном формате, но удобство редактирования текста и групп после импорта зависит от Figma. **Настоящий Figma-файл создан:** https://www.figma.com/design/Gh6UqShvMOH9IWPghqE95P — в нём размещены шесть редактируемых экранов 390 × 844 с текстовыми слоями, карточками, полями ввода и компонентами. Для интерактивной проверки переходов без Android Studio можно открыть `prototype.html` рядом с шестью SVG. Стиль и карта переходов дополнительно сохранены в `figma-handoff.json`.

| Экран | Файл | Основное действие |
|---|---|---|
| 1. Вход | `01-login.svg` | Войти или зарегистрироваться |
| 2. Зал | `02-hall.svg` | Выбрать компьютер на схеме |
| 3. Бронирование | `03-booking.svg` | Выбрать тариф/время и подтвердить |
| 4. Мои брони | `04-my-bookings.svg` | Посмотреть статус, отменить будущую бронь |
| 5. Сессия | `05-session.svg` | Посмотреть таймер, продлить |
| 6. Профиль | `06-profile.svg` | Просмотреть роль и выйти |

## Визуальный стиль

- Холст: **390 × 844 px**, вертикальный Android-экран.
- Тёмный фон `#0D1728`, карточки `#1B2942`, зелёный акцент `#21B98E`, основной текст `#EEF2FF`.
- Шесть пунктов навигации внизу. Реальная Android-версия пока переключает разделы одной Activity, отдельные Fragment ещё не созданы.
- Координаты компьютеров Android получает из SQL Server через API, а макет зала показывает **условную расстановку**. Содержимое макетов демонстрационное, не реальные пользовательские данные.

## Для отчёта и защиты

1. Открыть `docs/design/prototype.html` в браузере после клонирования репозитория: это локальный кликабельный макет, не рабочая Android-версия.
2. Открыть существующий Figma-файл по ссылке выше: шесть кадров уже созданы как редактируемые объекты, а не вставлены едиными картинками. SVG остаются резервным исходником.
3. Добавить стрелки прототипирования: Вход → Зал → Бронь → Мои брони → Сессия → Профиль; из «Мои брони» предусмотреть отмену.
4. После реальной сборки сделать скриншоты Android и сопоставить с макетами — **сейчас таких скриншотов нет**.
5. Не выдавать SVG-макеты за работающий APK или результаты проверки.

## Состояние

В Figma созданы шесть фреймов, объединённых локальными компонентами и цветными переменными. Проверены имена, размеры 390 × 844 и границы содержимого: ни один блок не выходит за пределы своей контентной области. Однако кликабельные связи Figma Prototype пока не настроены и могут быть добавлены вручную. HTML-макет в этой папке остаётся отдельной кликабельной демонстрацией. Это не скриншоты Android, работоспособность приложения не подтверждена.
