# Панель администратора GamingClub (Windows / WPF)

**Статус:** исходники созданы, запуск в Visual Studio пока не проводился.

## Доступ

Войти под учётной записью с ролью `ADMIN`. JWT хранится только в оперативной памяти приложения. Выход очищает токен и списки административных данных. Регистрация сама по себе создаёт только `VISITOR`; назначение администратора выполняется вручную в тестовой БД по `docs/desktop-verification.md`.

## Функции

**Тарифы:** загрузка всех тарифов, в том числе отключённых; создание `HOURLY`, `PACKAGE`, `NIGHT`, `HAPPY_HOURS`; отключение существующего тарифа по ID. Для `PACKAGE` задайте целое число минут; для `NIGHT` и `HAPPY_HOURS` окно `HH:mm`; для `HOURLY` дополнительные поля должны быть пустыми. Цена: десятичное число с точкой, например `120.00`.

**Бронирования:** просмотр последних 100 записей со статусом, логином, номером компьютера и UTC-интервалом. Можно отменять выбранную будущую активную бронь через кнопку с подтверждением. Пока нельзя редактировать интервал или фильтровать список.

**Отчёт:** выбрать UTC-период до 31 дня, запросить процент загрузки и сохранить CSV. Выгрузка проходит через защищённый административный API, а не через `/api/dev/`.

**Сессия:** продление действующей брони с указанием ID и нового времени UTC. Сервер проверяет пересечения, рассчитывает доплату и сохраняет изменения транзакционно.

Перед проверкой отмены на уже созданной базе примените `database/migrations/001_void_pending_payments.sql`. Инструкция: `docs/cancellation-verification.md`.

## Проверка после сборки

1. Запустить SQL Server и ASP.NET Core API с JWT по `docs/auth-verification.md`.
2. Открыть `src/GamingClub.Desktop/GamingClub.Desktop.csproj` в Visual Studio на Windows.
3. Проверить, что запросы списков/отчётов до входа не выполняются.
4. Войти как `ADMIN`; таблицы тарифов и бронирований должны загрузиться.
5. Создать новый почасовой тариф, обновить список, отключить его и проверить `IsActive=0`.
6. Создать тестовое бронирование с Android или Swagger и обновить таблицу.
7. Запросить отчёт за выбранный интервал и выгрузить CSV.
8. Выбрать будущую бронь и отменить; проверить статус `CANCELLED` и `Payments=VOID` (только неоплаченные начисления).
9. Выйти; административные таблицы должны очиститься.

Для сетевого развёртывания необходим HTTPS. Текущая версия рассчитана только на локальную учебную проверку.
